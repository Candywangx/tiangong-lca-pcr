# 煤焦油杂酚油压力浸渍实木铁路枕木

## 1. 范围与适用性

本制造方法适用于采用已识别煤焦油杂酚油混合物进行压力浸渍、经有记录的沥液及验收后交付的新制实木铁路或有轨电车枕木。有界路线从运抵处理厂的已制造未浸渍枕木坯开始，包括实际发生的厂内干燥及处理前机械加工、压力浸渍、末期真空与回收、围护滴漏区存放，终止于处理厂门口的成品验收交付。各阶段聚合为一个前景单元，分别保留阶段记录，只设一个最终产品输出。木种和处理条件保持产品特定 [usda-wood-handbook-2021; epa-wood-preserving-1999]。

本清单覆盖电动设备以及电加热或外购热水供热，按实际情况纳入气干、间接窑干调理或 Boulton 真空沸煮调理。直接蒸汽调理、现场燃料燃烧、热氧化装置、现场废水排放、硼酸盐联合处理、额外加入煤焦油或石油稀释剂、其他药剂体系、仅表面涂刷或浸泡、胶合或复合枕木、混凝土或钢枕、旧枕及服役维护，需要另行审查的路线扩展；未经补充原子交换和证据，不能用本有界清单表示。电阻加热电量只记录一次，不再同时记录为外购热。

未浸渍坯料是与浸渍成品不同状态的输入。制造质量声明不确定服务年限、铁路运输服务功能单位、更换周期或与其他枕木材料的功能等价。安装、运营、服役浸出及寿命终止处理不属于本前景单元；下游生命周期研究应独立规定。

保留声明木种和整根锯制实木浸渍枕木。RailExim 记载采用单一 Type C 杂酚油的榉木运行线枕及栎木道岔/桥梁构件；Impregnatsiya 2000 记载实用 Rueping/Lowry 高压釜处理。这些工业主证支持产品形态、单一完整药剂路线及铁路接收功能，不给默认木种、尺寸、配方、保持量、寿命或本厂公用工程配置。其标准标识是规格限定，本 PCR 不声称读过付费标准全文。[railexim-sleepers; impregnacia-sleepers]

每数据集只选有操作记录的实际周期：Rueping 初始空气加压、保压充液、升液压、回液及末期真空；Lowry 充液前无初始空气加压或初始真空；Bethell 先抽真空、不破真空充液再加压及回液。第二次 Rueping 若实际发生须另记周期，不产生第二根枕木。不能平均这些压力曲线或将图15-5的初始真空改称 Rueping。Boulton 是热油真空调理，不是第二配方。按适用买方规格采集真实时间、压力、温度、渗透及保持量，不采用手册数值。USDA 部分 BMP 包括末期蒸汽；本无直接蒸汽清单只在真实操作及规范允许缺席时适用，否则经审查扩展实际蒸汽、冷凝液及其他交换。[usda-wood-handbook-2021 15-8,15-15-17,15-22-23; epa-wood-preserving-1999 10.8.1]

煤焦油杂酚油浸渍保留实木构件，将真实完整油剂混合物引入木材孔隙；干燥/调理除水时也可能释放有机组分。USDA 将这类油剂描述为对木材基本惰性，区别于反应性水载盐体系。不得虚构化学计量固化反应、生成水、纯 PAH 配方或固定混合物组成。此定性描述不能证明具体厂零化学变化或零损失：实际降解、排放物种、冷凝液、保留组成和不合格品须独立采集。Type C 是工业实例，不是每个数据集的指定配方；真实商品混合物及验收状态须由供应方、安全数据表、分析和接收方记录识别。[usda-wood-handbook-2021 15-8,15-17; epa-wood-preserving-1999 10.8.2; railexim-sleepers]

### 实物阶段及来源库存继承

绘制真实林地/采伐来源 → 制材厂锯切成实木枕坯 → 实际气干/窑干、定尺/adzing/钻孔/刻痕 → 实际热油调理 → 选定压力周期 → 回液、冷凝及真空 → 围护沥液/存放 → 检测放行 → 成品保管及真实铁路接收方。逐阶段声明场址、所有权、期间和材料状态。供应方已做林业/锯切/干燥/加工及运输经状态匹配坯料 provider 和逐交换向量继承一次；厂内仅采集剩余实际操作。完整枕坯 provider 不能再加一份原木制造负荷。缺上游覆盖应逐阶段披露，不记零，也不从购成品和包装推定完整生命周期。[usda-wood-handbook-2021 Ch.6/13/15; wegland-sleepers]

未分配实物 V 独立于负荷账 A。对每阶段或库存账户及每来源/形态/相态/单位，opening + external_in + internal_in + actual_formation = closing + external_out + internal_out + actual_consumption。external_in/external_out 跨越前景单元边界；internal_in/internal_out 是该单元内成对的接收/发出端。同态转库或阶段交接使用 internal_in/internal_out，不记 formation。每条内部交接两端量及向量相等；全单元合并时这些成对内部转移相消。绝干木、水、整药剂及其独立成分分析、实装金属、每包装、能量及逐物种排放分别记录。所有原料、WIP、新/旧FG和复用库存携带原provider及逐交换继承负荷向量 b；单一总碳足迹标量不足。A 分配份额不乘实物木/水/药剂/共产品质量或内部交接。actual_formation 与 actual_consumption 将真实的被跟踪状态变化与前序状态的对应取出配对，绝不创守恒物质质量，也不在实收上再加一份。同一状态转换事件不得又记为内部转移；合并状态时，仅在独立核对的守恒物质量基上相消其成对形成/消耗，保留真实外部损失及非守恒物种变化。绝干木、水、整药剂及实测组分分区独立闭合；机械加工及首次验收不创木质量。

B 为完整期间同木种/构型/状态/路线首次验收新制净 kg（firstQ），当期新产期末FG计一次。grossDispatch 为真实对外发货，不等于 firstQ：区分期初旧FG、新生产、购入FG、同件返回、报废及期末FG。原Qc服务和同件返工不创造新 B 或第二木料provider；继承原向量后只加本次实测服务负荷。真实外返须有该同件前次outward事件。先细分cohort再归属。失败Q0、闲置、启动停机、清理和存放数量及负荷不能丢；不可分负荷保留明确待审池，不作成功批次平均。B=0 保留池，不除零也不报零强度。

整木料、完整商品药剂及每个湿废混合流均只连一次provider/接收接口。干木/水、药剂组分及湿废固液分析是同一实物分区，不另加到输入总量。药剂外部原始实收和供应方退料腿独立保留，不与期初罐+新加料-退料-期末罐这一净使用诊断混同。泵送、回滴和复用浴液周转是内部循环，不是新制造。保持量、水、空气物种/相态、废物组成及热独立实测；一个差额不能求多个未知。未知不是0。

### 包装实收、保管和外出

每个真实组件保留材质、形态/型号、单向/复用用途、方向、原量/单位、receipt、owner/custodian、同件号和既有逐交换向量。P 是真实购得实收，整批采购即使没有独立包装发票仍 P。N_ext 是首次外来真实非购，含核实的借租/委托/非购随货。ER 是有同件前次outward的真实外返。入口互斥；内部回用均不是。既有 X 若已明确定义真实新入口可保留，换字母或删除重复 OTHER 不产生新实收接口。

每组件/来源/单位：opening_empty/raw/WIP/FG/reusable + P + N_ext + ER = closing_empty/raw/WIP/FG/reusable + each_actual_external_outward + waste。所列库存状态是互斥实物保管位置，同件同一时点只计一次；已随raw/WIP/FG的复用件不再计入空闲reusable库存。内部领用/退库双端对应；保留原料随货包装、首次外来垫块和发货包装，不能只记领用损失。随货发出、退还所有者、废物腿各有接收方、方向、数量和原向量，并有实收时间、来源和 cohort。grossDispatch 包装皮重独立于枕木质量对账。进料、发货及返回各腿保留真实总运输量，不能以回程净掉去程运输。经审查扩展需要 tkm 时，仅将该腿真实载运 kg 除以 1,000 换成吨一次，再乘该腿实际 km；不得编距离或空返载重。制造provider只挂真实购得/新造对应份额一次，整供容器/组件不得再叠加组成材料制造。借租与外返仍带原向量及本次搬运/清理负荷，不因无发票零负荷，不造新Q、无限次数或避免生产信用。其他实际薄膜、纸、托盘或污染包装各增具体卡；此处条件卡不能代理。

## 7. 分配与共产品处理

本有界单元通常只有一个验收产品及分别处理的废物。先保留原单位，将真实 rate 按实测时间及范围积分一次，再换算及归属。首先细分无关生产并跟踪真实批次；共用公用工程按实测因果用量（处理罐周期、实测供热负荷或设备运行）分配，逐交换记录实物基准。废物处理归属产生批次，不假设避免处置或能源信用。内部回收药剂不是联产品，不产生替代信用。

保持未分配实物过程账完整：收到木材、产品、边角料、不合格品、水、保留药剂、库存及内部转移。环境负荷只能在细分后通过另一套账进行分配。不得将实物联产品输出质量或内部链接两端乘以负荷分配份额。若存在可销售清洁木材联产品或混合产品批次，应修订流分类，分别审查因果或经济分配及敏感性；不能静默将废物改为联产品或设默认份额。经济分配仅能处理真实细分及逐交换因果归属后、有证据的同门联产品不可分剩余，采用同期实测数量及同量基实际价格/收入。记录剩余池、价格、期间及敏感性；价格或因果范围未知仍未决。同一 cohort 既有逐交换向量和新增归属负荷进入 A，最后仅除以该 cohort 的 B 一次。原 Qc 服务、返工及再次交付继承原向量，只增加真实本次服务负荷，不再产生产品分母。这些是前景采集规则，不是转用锯材调查收率或分配百分数。

## 9. 校验规则

要求验收净输出质量为正，sleepers_out 仅链接一个最终产品行，声明产品及坯料状态和木种，核实精确参考身份并包含全部必需限定信息。两种语言中每卡及每协议使用相同 kg 分母。拒绝从循环泵送量计算新消耗、未定义保持量体积及质量基准、用未浸渍身份表示浸渍木材以及将处理后未经限定烘干失重等同于水。

全部储罐及回收库存须与保留混合物及实测废物、排放负载核对；标记未解释差额和缺失分析代表性。核查相态、物种、接收介质和不重叠排放源。不得将 VOC 或 PAH 总量与物种交换叠加，不得将烟气入口与出口叠加，不得把已捕集污染物与空气残余释放叠加。PM 区间互斥。供应方热量基准未知、流身份不可用或相关源未测量均为不完整，不能记零或通过。实际药剂、供应等级、直接水体或土壤排放及范围外燃料或蒸汽路线变化，须在应用前逐项核实扩展。

归一化前逐原子行核对来源/provider、原量/单位、形态/相态、采集协议和raw/WIP/新旧FG/reusable期初期末向量。firstQ及closing_new_FG只计一次，并与grossDispatch、原Qc服务、真实返回及失败Q0/idle/cleanup对比。先闭合实物V，再独立审A。工业网页不提供分配审批或本厂数值配方。报告实际样本量、期间、范围/统计量和不确定性；不设默认重量、密度、收率、保持量、价格、因子或信用。缺范围属于待实测证据，不是0或AI估算界限。

独立核实真实气相/气溶胶、物种/CAS及接收compartment。totalPM、COD、NOx和总金属是各自分析指标，不对应单一分子量，也不能从一个平衡差额拟合多个未知。捕集污染物在对应湿混合废物流计一次，残余释放另测。非空气接收介质须独立具体匹配交换。条件性未发生须实证，未知保持不完整。完整药剂 UUID 未绑定是 creosote_in 及真实退料接口上的上游身份/provider 缺口，与其他未决供应交换一样，本身不使有实物依据的枕木方法或独立评估的参考失效。相容整配方/provider 核实前，数值上游连接仍不完整，不得替换为纯 PAH。真实混合物形成/组成、产品/接收证据或有记录路线适用性缺失是另一个实质缺口，必须具体披露。普通辅料 UUID 缺口同样逐行保留在元数据。有限计量检查或命令exit0永不建立科学、翻译、具体厂数据或发布审批。
