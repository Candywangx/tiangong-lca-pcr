# CPC 64242 draft mapping decision

The actual UNSD CPC3.0 Explanatory Notes30June2025, printed363, defines `Domestic non-scheduled air transport services of passengers` with aircraft of any type including helicopters and accompanying passenger baggage/items carried without extra cost. This code requires actual **domestic** and **non-scheduled** service qualification. For scheduled leaves the actual predetermined route/schedule applies; non-scheduled leaves expressly exclude sightseeing64134 and aircraft-with-crew rental66031. This decision does not invent technology limits from available UUIDs. Actual original: https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/CPC_Ver_3.0_Exp_Notes_30Jun2025.pdf .
