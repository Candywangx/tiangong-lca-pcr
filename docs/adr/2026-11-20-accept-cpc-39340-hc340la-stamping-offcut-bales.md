# CPC 39340 segregated HC340LA cold-stamping offcut bales

Accept the narrower association for segregated metallic offcuts from cold stamping one documented uncoated HC340LA sheet grade. The finished reference is a qualifying compressed bale supplied to a named ferrous recovery receiver. It requires actual bale-specific acceptance and original sheet and stamping evidence. Mill scale, remelted ingots, mixed grades and loose feed sit outside this scope.

Measure the first qualifying net bale mass before any repeated dispatch or return. Include burdened source sheet and split actual stamped-blank and offcut co-functions using the documented joint-process hierarchy. Record mechanically needed preparation and delivery against each original lot. The PCR retains candidate authored methodology and aligned Chinese.

See [the independent review](../reviews/cpc3-115-resume-20261120/39340.json).
