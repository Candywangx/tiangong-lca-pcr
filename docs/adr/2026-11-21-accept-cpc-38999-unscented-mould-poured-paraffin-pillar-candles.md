# CPC 38999 unscented mould-poured paraffin pillar candles

Accept a narrower association for a complete unscented mould-poured cylindrical petroleum-paraffin pillar candle, with the specified integrated cotton wick and the actual colour formulation. First release requires that the declared complete shape, wick configuration and intended normal candle function satisfy the documented order requirements. Finished wax stock, an empty vessel and an unburnable decorative imitation have different functions.

Count each qualified first-release event once and measure the complete conditioned net candle mass. Distinguish the factory’s test and rework consumption, retained work in progress, postrelease handling and real returns. Separate consumer burning from any observed factory trial. Retain separate inventories for the actual wax and other constituents and the package through its movements.

See [the independent review](../reviews/cpc3-115-resume-20261120/38999.json).
