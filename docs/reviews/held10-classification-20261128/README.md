三个选定 PCR 的严格检查完成 **354 项计量检查、0 跳过**，保留 **57 条数量范围警告**。这些不是科学批准，也不表示实际工厂已提供采集数据。完整验证和新源码的上游资格结果将在 PR 附上；旧 #167 的绿色运行不能代替此次结果。历史 149 份审阅文件保持不变，本次记录只取代上述三个代码的暂缓决定。

分类依据为 UNSD 2026 年 10 月白皮本与 WCO HS 2022 正式原文；HS 2022 是 CPC 当前解释引用的版本，不将其偷换成未来 HS 版次。本次为主控分类复核，不声称外部专家独立科学审查或海关约束性裁定。未修复七份稿及八个原始模板的文件摘要均保持原样。
